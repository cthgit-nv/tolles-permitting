# Q-20260924-fmdp-lead-agency: For FMDP, should BLM lead with Reclamation cooperating, should they be joint leads, or should each agency issue its own decision?

- **Raised:** 2026-09-24 by permitting desk
- **Project:** FMDP (affects CHIP Application 1)
- **Sensitivity:** PRIVILEGED (builds on Aug 14 memo Q2)
- **Blocking?** Yes. Sets the NEPA document structure for Application 2.
- **Who can answer:** Holland & Hart; BLM and Reclamation at pre-application; research (A-usc-42-4336a)

## Context

FMDP needs both BLM (Title V) and Reclamation (Part 429) authorizations (facts F6). The
Aug 14 memo Q2 asked a version of this for the old combined structure and noted the
former cooperating-agency rule (43 C.F.R. 46.225) was removed in July 2025; the statute
now governs lead and cooperating roles (42 U.S.C. 4336a). New wrinkle: Reclamation also
decides Application 1. If Reclamation cooperates on the FMDP EA while separately
categorically excluding Application 1, the FMDP EA should treat Application 1 as a
separate, independently useful action (context and cumulative effects), never as part of
the proposed action. A single Reclamation office handling both invites the argument that
Reclamation itself sees one project.
