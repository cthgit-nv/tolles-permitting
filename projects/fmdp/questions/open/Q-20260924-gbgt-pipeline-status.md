## Context

Cory, 2026-09-24: the corridor will share alignment and access with the GBGT pipeline "that will be built" and with the existing NV Energy road and transmission line. The Aug 14 memo (Background 5, Q3) described the Great Basin pipeline as existing disturbance to parallel, which supported a FONSI. If the pipeline is not yet built, only the NV Energy road and line are existing disturbance; the pipeline is a reasonably foreseeable future action for cumulative effects, and if it is an interstate pipeline its own review likely runs through FERC. Coordination options: shared corridor agreement, joint or adopted analysis, sequencing. Documents describing the pipeline as existing need correcting.

**Research 2026-09-24:** Great Basin's 2028 Expansion (FERC pre-filing PF26-5, about 195
miles including Churchill County; BLM a planned cooperating agency) may be this pipeline;
unconfirmed. Precedent: in 2024 the Sierra Front FO adopted FERC's EA for a Great Basin
pipeline ROW amendment (`A-prec-blm-great-basin-expansion-2024`). IBLA treats ROWs sharing
a corridor as not connected where each would proceed without the other
(`P-shared-corridor-rows-not-connected`).
